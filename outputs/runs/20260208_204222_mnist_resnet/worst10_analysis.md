## 2. 混淆對統計 (GT → Pred)

- **2 → 8**（3 筆）：2 與 8：同上。
- **0 → 8**（1 筆）：0 與 8：0 若有缺口可能被看成 8。
- **4 → 6**（1 筆）：4 與 6：4 的開口大或 6 的圈不明顯時，下半部可能混淆。
- **2 → 3**（1 筆）：2 與 3：2 的上弧與 3 的轉折在書寫風格相近時易混。
- **5 → 0**（1 筆）：視覺或書寫上相近，或邊界樣本。
- **9 → 4**（1 筆）：9 與 4：同上。
- **1 → 3**（1 筆）：視覺或書寫上相近，或邊界樣本。
- **9 → 5**（1 筆）：9 與 5：9 的圈與 5 的弧線、轉折在書寫模糊時易混。

## 3. 可能原因摘要

- **視覺相似**：4/9、3/5/8、7/1、2/7、5/6、0/6/8 等對在 28×28 下本就易混。
- **書寫模糊**：手寫介於兩類之間 → 模型 confidence 低、易錯。
- **模型**：本 run 為 **RESNET**；若為 MLP 則無局部結構，對細微筆畫較不敏感；CNN 則較能抓局部，但邊界樣本仍可能進 worst 10。
