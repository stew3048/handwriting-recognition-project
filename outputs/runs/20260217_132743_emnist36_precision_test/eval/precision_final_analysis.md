與先前版本比較（平衡 test，每類 800）：
- CNN: 89.11%
- 一般 ResNet: 90.33%

- ResNet+CL v2 (64d): 90.77%

**結論**：整體準確率略低於 v3（91.19%），但仍在合理範圍（89.82%）。

## 3. 訓練過程：O/0、I/1 中心距離變化

從 `o0_i1_metrics.csv`：

### O/0 中心距離
- **Epoch 1**: 1.6247 → **Epoch 25**: 0.1847（**大幅拉近**）
- **兩類準確率**：67.42% → 70.74%（**+3.3%**）

### I/1 中心距離
- **Epoch 1**: 3.0979 → **Epoch 25**: 0.2739（**大幅拉近**）
- **兩類準確率**：54.12% → 32.12%（**-22%**，變差）

**矛盾點**：
- 中心距離變近（從 3.1 → 0.27），但準確率反而下降（54% → 32%）。
- 可能原因：**過度拉近導致兩類在 embedding 空間重疊**，反而更容易混淆。

## 4. 與先前版本比較（O/0、I/1）

| 版本 | O/0 兩類整體 | I/1 兩類整體 | 整體 Test Acc |
|------|--------------|--------------|---------------|
| ResNet+CL v3 | 71.27% | 81.16% | 91.19% |
| **精準打擊版** | **~69.5%** | **~50.9%** | **89.82%** |

**結論**：
- **O/0**：精準打擊版略低於 v3（69.5% vs 71.27%），但差距不大。
- **I/1**：精準打擊版明顯較差（50.9% vs 81.16%），**I/1 的表現反而退步**。
- **整體**：精準打擊版整體準確率也略低（89.82% vs 91.19%）。

---

## 5. 可能原因分析

1. **過度聚焦**：只對 0/O/1/I 過採樣 + 強擴增，可能讓模型「過度學習」這四類，反而在 test 上表現不穩。
2. **I/1 中心距離拉太近**：從 3.1 → 0.27，可能導致兩類在 embedding 空間重疊，反而更容易混淆。
3. **強擴增的副作用**：50% 強擴增可能讓模型學到「變形後的樣本」，但在 clean test 上表現反而下降。
4. **Test 分布不同**：訓練時 0/O/1/I 過採樣（15000 vs 5000），但 test 是平衡的（800 vs 800），分布不一致可能影響表現。

---

## 6. 建議

1. **調整 Center Loss alpha**：目前 16-25 epoch 線性增加到 0.15，可能拉太近；可考慮降低上限（例如 0.10 或 0.12）。
2. **降低強擴增比例**：從 50% 降到 30-40%，讓模型多看到「清晰樣本」。
3. **檢查 I/1 混淆矩陣**：看是 I 被誤判成 1，還是 1 被誤判成 I，針對性地調整。
4. **Test 也過採樣**：讓 test 分布與 train 一致（四類 2400、其餘 800），看是否改善。

---

**總結**：精準打擊策略在 **O/0** 上有小幅改善（但不如 v3），但在 **I/1** 上反而退步。整體準確率略低於 v3。可能需要調整 alpha 上限或擴增比例。
